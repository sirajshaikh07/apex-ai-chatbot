# Enterprise Application Integration Guide
## Oracle 26ai + APEX 26.2 + In-Database Vector Search + Local LLM (Ollama)

This document provides complete technical specifications, code examples, and best practices for integrating external enterprise applications (Web, Mobile, Backend Microservices, CRM, ERP) with the Enterprise Policy AI RAG Chatbot.

---

## 1. System Architecture Flow

```
[ External Enterprise Application ]
 (React / Angular / Java / Python / Mobile)
                    │
                    ▼ HTTP POST (JSON)
[ ORDS 26.3 REST Web Tier (VM2) ]
 http://92.4.82.132:8080/ords/aidemo/api/chat
                    │
                    ▼ JDBC Net8 (Port 1521)
[ Oracle AI Database 26ai Free (VM1: FREEPDB1) ]
 ├── Schema: AIDEMO
 ├── Package: POLICY_RAG_PKG
 ├── ONNX Model: ALL_MINILM_L12_V2 (384 Dimensions)
 ├── Vector Chunk Search: VECTOR_DISTANCE(..., COSINE)
 └── Grounded Prompt Assembly
                    │
                    ▼ HTTP Request (Port 11434 via APEX_AI)
[ Ollama Local LLM Runtime (VM2) ]
 └── Model: llama3.1:8b (Context: 8192, Temperature: 0.0)
                    │
                    ▼ Grounded Answer + Citations
[ JSON Response returned to External Application ]
```

## 2. REST Endpoint Details

### 2.1 Basic Information
* **Base URL**: `http://92.4.82.132:8080/ords/aidemo`
* **Resource Path**: `/api/chat`
* **Full Endpoint URL**: `http://92.4.82.132:8080/ords/aidemo/api/chat`
* **HTTP Method**: `POST`
* **Content-Type**: `application/json`
* **Authentication**: Open / Anonymous (Can be secured with ORDS OAuth2 or Basic Auth)
* **Average Response Latency**: 7 – 10 seconds (Full In-DB Vector Search + 8B LLM CPU generation)

---

### 2.2 Request Specification

#### Headers
| Header | Value | Required | Description |
|---|---|---|---|
| `Content-Type` | `application/json` | Yes | Specifies JSON payload format |
| `Accept` | `application/json` | No | Recommended for client parsing |

#### Request Payload (JSON Schema)
```json
{
  "question": "string (required, max length 4000 characters)"
}
```

#### Example Request
```json
{
  "question": "What is the guaranteed response time for a Severity 1 Critical Outage?"
}
```

---

### 2.3 Response Specification

#### Success Response (`HTTP 200 OK`)
```json
{
  "status": "success",
  "question": "What is the guaranteed response time for a Severity 1 Critical Outage?",
  "answer": "The guaranteed response time for a Severity 1 Critical Outage is strictly under 15 minutes. According to Document 01_cloud_sla.txt: \"Severity 1 Critical Outage: System completely unavailable. Response time is strictly under 15 minutes with 24x7 phone, SMS, and pager alerts.\"",
  "sources": "01_cloud_sla.txt, 05_support_escalation.txt"
}
```

#### Response Fields Description
| Field | Type | Description |
|---|---|---|
| `status` | `string` | Execution status (`"success"` or `"error"`) |
| `question` | `string` | Echo of the input question |
| `answer` | `string` | Grounded, factual response generated by `llama3.1:8b` strictly based on corporate policy documents |
| `sources` | `string` | Comma-separated list of policy files retrieved via Vector Distance search as citation references |

#### Out-of-Domain Guardrail Response (`HTTP 200 OK`)
When a user asks a question not covered by company policy documents:
```json
{
  "status": "success",
  "question": "What is the corporate pet policy for bringing dogs to the office?",
  "answer": "Information not available in company policy documents.",
  "sources": "05_support_escalation.txt, 03_data_security.txt"
}
```

#### Bad Request Error (`HTTP 400 Bad Request`)
If `question` parameter is omitted:
```json
{
  "error": "Missing required JSON parameter: question"
}
```

### 3.2 JavaScript / TypeScript (Node.js, React, Angular, Vue, Next.js)

```javascript
// Using Fetch API (Browser or Node.js 18+)
async function askPolicyAI(questionText) {
  const ENDPOINT = "http://92.4.82.132:8080/ords/aidemo/api/chat";

  try {
    const response = await fetch(ENDPOINT, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ question: questionText }),
    });

    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }

    const data = await response.json();
    console.log("Answer:", data.answer);
    console.log("Sources:", data.sources);
    return data;
  } catch (error) {
    console.error("Failed to query Policy AI:", error);
    throw error;
  }
}

// Example Execution
askPolicyAI("How many days of annual earned leave are granted each calendar year?");
```

### 3.3 Python (Backend Microservices, FastAPI, Django, Flask)

```python
import requests

def query_policy_ai(question: str) -> dict:
    url = "http://92.4.82.132:8080/ords/aidemo/api/chat"
    headers = {"Content-Type": "application/json"}
    payload = {"question": question}

    response = requests.post(url, json=payload, headers=headers, timeout=30)
    response.raise_for_status()
    
    data = response.json()
    return {
        "answer": data.get("answer"),
        "sources": data.get("sources"),
        "status": data.get("status")
    }

# Example Usage
if __name__ == "__main__":
    result = query_policy_ai("What is the submission deadline for travel expense reimbursement claims?")
    print("AI Answer:", result["answer"])
    print("Cited Sources:", result["sources"])
```

### 3.4 Java (Spring Boot / Jakarta EE)

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.Map;

public class PolicyAIService {
    private static final String API_URL = "http://92.4.82.132:8080/ords/aidemo/api/chat";
    private final HttpClient httpClient = HttpClient.newHttpClient();
    private final ObjectMapper objectMapper = new ObjectMapper();

    public String askQuestion(String question) throws Exception {
        Map<String, String> payload = Map.of("question", question);
        String requestBody = objectMapper.writeValueAsString(payload);

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(API_URL))
                .header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString(requestBody))
                .build();

        HttpResponse<String> response = httpClient.send(request, HttpResponse.BodyHandlers.ofString());
        return response.body();
    }
}
```

### 3.5 C# / .NET (Enterprise Web / Desktop / Azure Apps)

```csharp
using System;
using System.Net.Http;
using System.Text;
using System.Text.Json;
using System.Threading.Tasks;

public class PolicyAIClient
{
    private static readonly HttpClient client = new HttpClient();
    private const string ApiUrl = "http://92.4.82.132:8080/ords/aidemo/api/chat";

    public async Task<string> AskQuestionAsync(string question)
    {
        var payload = JsonSerializer.Serialize(new { question });
        var content = new StringContent(payload, Encoding.UTF8, "application/json");

        HttpResponseMessage response = await client.PostAsync(ApiUrl, content);
        response.EnsureSuccessStatusCode();

        return await response.Content.ReadAsStringAsync();
    }
}
```

## 5. Security & Production Hardening Recommendations

1. **SSL/TLS Termination**:
   - For production, expose the API behind an Nginx or Caddy reverse proxy on port 443 with HTTPS (e.g., `https://ai.enterprise.com/api/chat`).
2. **ORDS OAuth2 Authentication**:
   - To restrict access to trusted internal clients, enable OAuth2 client credentials in ORDS (`OAUTH.CREATE_CLIENT`).
3. **CORS (Cross-Origin Resource Sharing)**:
   - ORDS handles CORS natively. To restrict access to specific frontend domains, configure `security.cors.origins` in ORDS configuration.
4. **Rate Limiting**:
   - Since inference runs on VM2 CPU (`llama3.1:8b`), implement rate-limiting at your API Gateway or reverse proxy (e.g., max 10 requests/minute per client).
